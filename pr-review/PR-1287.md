## Description

Adds a search box and status filter to the request list, as in ticket RD-212.

- Search highlights the matching text in the title so agents can see why a row matched
- List auto-refreshes every 10s so agents see new tickets
- Clicking a row opens the request
- Sorted by priority so critical ones are at the top

I also tweaked the API: search now supports regex (power users asked for it), and I raised the page size limit so we can load all requests at once and sort them on the client.

**Testing:** tested manually in Chrome, works fine. Didn't add unit tests yet because the deadline is tomorrow. Will add them in a follow-up.
